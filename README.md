Voting Eligibility System

Project Description

This is a simple Python 3 project that checks whether a person is eligible to vote based on age and Indian citizenship.

Features

- Takes name, age, and citizenship as input.
- Checks voting eligibility.
- Shows the reason if a person is not eligible.
- Handles invalid age input using exception handling.
- Allows checking multiple voters using a loop.
- Displays the total number of voters checked.

Eligibility Criteria

- Age must be 18 or above.
- Person must be an Indian citizen.
- Age must be a whole number between 0 and 120.

Technologies Used

- Python 3
- Conditions (if-elif-else)
- Functions
- Loops
- Exception Handling

How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the Python file.
4. Run the following command:

python voting_eligibility.py

Expected Output

Name: Aman
Age: 25
Indian citizen (y/n): y

Aman is eligible to vote.
